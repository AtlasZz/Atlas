# 土地利用图去水印：两条路线与适用边界

记录时间：2026-11-25。工作目录 `D:\Workspace\DSHarness`。

## 问题形态

源图为一张区县级土地利用图（1035×1249，RGB，`土地利用图_去水印_保真版.png` 的原始输入尺寸）。水印是压在整图上的**大型浅灰字**（"杭州…"类），并非半透明 logo：

- 在图外浅色空白底图上对比明显，灰阶差可达数十级；
- 在图内彩色图斑上几乎不可见（图斑自身颜色饱和，水印被"淹没"）；
- 因此**只需处理图外区域**，图内可以做零改动 —— 这是能同时做到"干净"和"逐像素保真"的关键前提。

## 路线一：像素级保真（推荐用于正式用图）

做法只做亮度补偿，不做任何生成式重建：

1. 先分离出"地图本体"：对全图做连通域统计取最大连通域（本例约 466575 px），用"从补集边界洪泛 + 取反"填洞，得到实心地图掩膜 `Mfull`（占比 0.372），其补集即图外空白区。
2. 图外区用局部背景估计（大半径平滑/中值）反解水印覆盖度，再按"背景估计 − 实测灰阶差"回补，只改动可判定为水印的像素。
3. 用距离变换把掩膜向内腐蚀若干半径（r=44/18/10 等）做"保护区"，确保行政边界、图例边线、地名文字不被碰到；半径越大遮罩越大（r=44 时约 19.7–24.8 万 px，r=18/10 时遮罩为 0，说明水印只落在离图斑较远的空白处）。
4. 验收口径：改动像素占比约 15%（`changed frac ≈ 0.15`），落在深色像素上的改动仅 342 px（多为图例文字抗锯齿边缘的抖动），图例最大灰阶差约 60–67 但视觉不可辨；`浦江/兰溪/诸暨/东阳/金华/永康` 等标注、色块、边界细线逐像素未变。

产物：`土地利用图_去水印_保真版.png`（1035×1249，与原图同尺寸）。中间实验脚本在 `imgwork/`（`v3.py`–`v9.py`、`soft.py` 等），属一次性探索，未固化。

**已知残留**：图例"留白用地"旁有一个原图自带的小圆圈"◎"，去水印过程未动它；要清掉需另跑一版。

## 路线二：AI 重绘（仅作示意，不可量算）

用 `dsh-image-gen` 的 `edit_image`（默认通道 openai-compat / `gpt-image-2.5-sunburst`）整图重绘，水印视觉上更"干净"，但存在不可接受的性质：

- 输出被改成 1024×1024 方形，比例与原图不符；
- 图斑形状、边界细部、图例排版与原图均有出入 —— 生成式模型是"重画"而非"修复"。

产物：`土地利用图_去水印_AI重绘版.png`（1024×1024）。

**结论**：凡涉及面积量算、成果引用、内部审查的场合只能用保真版；AI 重绘版只能当汇报配图/示意图。

## 可复用要点

- 大型浅灰水印优先走"局部背景估计 + 覆盖度反解"，而不是整图 inpainting；inpainting 会改写地形/边界细节。
- 先做连通域找"图面本体"再定处理范围，比手工框选稳。
- 用多档腐蚀半径 + "被遮罩像素数随半径骤降为 0" 来验证保护区确实覆盖了关键要素。
- 用 `diff` 的百分位统计 + 指定行像素串对比（源 vs 输出）做肉眼之外的自校验，比只看预览图可靠。
