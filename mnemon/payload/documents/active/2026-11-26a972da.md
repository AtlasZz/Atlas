## 要表达的政策逻辑（用户原始需求）

生态保护红线内零星建设用地复绿并划入红线后，其**复绿规模**在**优先保障农民建房、农村公共基础设施、农村公共服务设施建设用地需求**之后，剩余部分可**折算为新增城镇建设用地规模**。核心是「先保障、后折算」的前置关系，而非简单相加。

## 图面组织：一条主流程 + 一处扣减支路

| 环节 | 图示表达 |
|---|---|
| ① 红线内零星建设用地 | 红虚线框＝生态保护红线范围；框内零散小绿块＝复绿地块；灰虚线框＝原建设用地范围，体现「零星、分散、单块小」 |
| ② 复绿规模 A | 绿色主卡，标注「复绿到位并划入红线后计量」 |
| ③ 剩余可折算规模 A−B | 浅绿公式卡 |
| ④ 新增城镇建设用地规模 C | 蓝色卡，内嵌「城镇开发边界」小示意图，标「经折算计入」 |
| 扣减支路（B） | 下方橙色框并列三类用地（农民建房／农村公共基础设施／农村公共服务设施），橙色箭头自框顶向上汇入主流程线，标「− B　先扣除」 |

底部结论条压成一行公式：**复绿规模 A − 优先保障用地 B = 剩余复绿规模 → 折算为 新增城镇建设用地规模 C**。

设计要点：支路箭头必须**向上汇入主流程线**（视觉上呈现「扣除」而非「并列」），这是全图唯一容易看错的逻辑点。

## 两处刻意的表述取舍

1. **不写折算系数**：图中统一用「按有关规定折算」，不落 1:1 或具体比例。理由是该图服务于政策逻辑示意，系数据口径需以上位文件为准，写死数值会把示意图变成越界的规范表述。若后续拿到明确折算口径，可在脚本中改成数值化表达（对应政策文本见 `47fe23e4-6718-44f2-ae8b-eef3a9e43453` 中第十一条 100% 折算与「不占用县域新增建设用地规模、不计入城镇开发边界扩展倍数」的定稿口径）。
2. **三类保障用地各附一句范围提示**（如「农村道路、供水供电等」）仅为示意，正式引用时应替换为文件原文表述。

## 环境与实现要点

- 用 Pillow 在 DSH 运行时 Python 下脚本绘制，而非 AI 生图——中文术语密集，脚本排版可保证文字与层级准确。
- 字体取系统微软雅黑 `msyh.ttc`（同目录另有 msyhbd/msyhl、simhei、simsun、Deng 等可用）。
- **字形坑**：小卡片内的 `▣` 字符在 msyh 下渲染成方框乱码，必须改用几何图形自绘徽标（画圆＋数字），不要依赖装饰性 Unicode 符号。
- 中文字体路径与已装库（Pillow 12.3.0 等）见 `021c3a66-f517-4400-9a9e-acacdaabeda2` 的环境限制段落。
- 迭代流程：出图 → 放大裁切局部（`_chk1.png`/`_chk2.png`）检查文字渲染 → 修排版（标签被图斑压住、图区与副标题过挤）→ 重跑。中文字体密集的图必须做局部放大校验，整图缩略看不出乱码。

## 可复用变体

脚本改参数即可产出：16:9 横向 PPT 版、单色（黑白打印）版、增补折算系数版。若同一政策主题还需其他示意图，沿用「主流程卡＋扣减支路＋底部公式条」骨架可保持一致视觉语言。
