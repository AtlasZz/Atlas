# 图像编辑接口改不动中文小字时：Pillow 定点去字 + 无损放大

记录时间 2026-11-23 至 11-24，工作目录 `D:\Workspace\DSHarness`。任务：按用户给的政策文本（《近期规划》工作组织 + 编制程序）用 dsh-image-gen 出一张白色背景、蓝色系、2:1 的流程图。

## 结论先行

`gpt-image-2.5-sunburst` 生图版式与文字基本可用，但**编辑接口不适合做「删几个字」这类微改**：改一次没删掉目标文字、还把另一处「报批」的「报」改成了「提」。最终交付改为**模型生图定稿一次 + Pillow 像素级定点手术**，并用「改动像素全部落在目标区域内」作为硬校验。用户要更高清时同样不重新生图，而是对同一张图做高质量放大，避免版式与文字漂移。

## 定点去字：列投影找字块，切片重排而不是涂抹

两个深蓝标签条里是「一、工作组织」「二、编制程序」。做法（`work/fix_labels.py`）：

1. 在标签条内部（y 范围如 171..250、623..692）按列统计非底色像素，得到**字形 run 列表**；汉字与标点各成一段，如 `[(86,129), (136,147), (183,226), (232,276), (281,324), (329,373)]`。
2. 需要删的序号正好是左侧若干 run（`25..34`、`84..126` 之类），保留从第一个真正的汉字 run 开始的片段。
3. 取标签条底色（实测 `(26,66,122)` / `(27,81,137)` 一类的深蓝），把保留片段**整段切出后平移重排**到条内居中位置，其余像素不动。
4. 关键取舍：**不重新渲染文字**（字体、字重、白色描边很难还原到看不出），只搬动已有像素，所以字形与描边必然与原图一致。

坑：第一次按「保留到最右 run」切，把条右侧的装饰性小元素也带进来了；改成以汉字首 run 与汉字末 run 为准，再按目标宽度居中。

## 校验口径（比肉眼看更可靠）

- 改动像素数（如 37575）与改动 bbox（如 `40 431 171 692`）；
- **断言 bbox 完全落在两个标签条内，条外差异像素 = 0**。这条断言能证明方框、箭头、序号圆圈、提示框一个像素没动。
- 再裁两块 240px 高的局部图放大看字形与居中效果。

## 放大：线性光 Lanczos + 阈值锐化

运行时 Python 只有 Pillow 12.3.0 / numpy 2.3.5，**cv2、scipy、skimage 均未安装**（可用 `python -c "import cv2"` 之类确认），所以不能走 cv2 的 EDSR/插值链，全部用 Pillow 实现：

1. sRGB → 线性光（gamma 2.2 附近）后做 Lanczos 放大，避免在高光/深蓝块边缘产生偏暗的插值色。
2. 转回 sRGB，再做**带阈值的 USM 锐化**（只锐化超过阈值的边缘），防止白底上出现黑边光晕；对比过 `v_usm90.png`、`v_acut_2.2.png` 等几组参数。
3. `save(..., dpi=(300,300))` 写入 300dpi 元数据，插进 Word/PPT 会按物理尺寸显示（4096 宽约 34.7cm，6144 宽约 52cm）。
4. 输出 2 倍与 3 倍两档，让用户按用途选。

必须如实告知用户：放大只增加像素、不产生新细节，200% 细看仍有插值柔化；要真正任意缩放锐利只能按版式重绘成矢量 PDF/SVG。

## 交付口径

- 中间废版（方图 1024×1024 的编辑版、标题多句号的版本、把「报」改错的版本）明确说明已弃用，只 present 定稿。
- 说明「改动只发生在哪两个标签条内、条外 0 差异」，比笼统说「看不出痕迹」更可信。
