# 用 dsh-image-gen 重绘 PPT 示意图（永农「认·连·调」页）

记录时间 2026-11-19，工作目录 `D:\Workspace\DSHarness`。

## 背景与结论

需求：读懂一张 PPT 示意图要表达的意思，据此重绘——**含义保持不变，视觉呈现与原图明显不同，让人看不出照搬**，且必须用 dsh-image-gen 插件生图。经 6 轮迭代后交付 `dsh-image-gen/image-5c958f0c.png`（1536×1024 PNG，可直接放进 PPT），只 present 最好的一张，并逐条对照用户要求做说明。

这类活的重点不在"画得好看"，而在两件事：**语义不能丢**（每一条政策动作都要在图上有对应图形），**图上的中文小字必须逐个核对**（模型生成的汉字极易出错）。

## 用户的验收口径（逐条落到图形上）

- **标题/副标题不进图**：画面只画地图本体，顶部留白，方便原页标题条另贴回去。
- **图例不写规模数字**：三条说明只写动作与对象（如「零星永农调出」「整治恢复连通」「认定永农」），**不出现万亩等数据**——模型会自动编造数字（曾出现 `0.11 万亩`，正确口径是 `0.1 万亩`），与其让它写不如规定不写。
- **「调」要画成动作**：在城郊园地缓冲带（2 处）、产创预控区、山地丘陵、郊野园地缓冲带各放**一小块孤立金色永农**，每块配绿色「调」标记 + 一根向外甩出的虚线箭头，表示"这一小块要调出去"。
- **「连」要画成过程**：连片块上缘/下缘各开一个缺口，分别嵌入园地（果树行列纹理）、林地（树冠纹理）、建设用地（灰色建筑块），三者用带箭头的「整治恢复」指向块内，表示垦造成永农；连片块内部用**浅色虚缝**分成 4 个原先是分离的片块，缝上加「接合」标记，旁注「相邻片块整治连通」。注意：缝线不能画成尺寸标注线，也不能压住"建设用地"这类标签。
- **用字准确**：图例「田坎」第二字必须是"土+欠"组成的"坎"，需放大原图逐字确认。中文里容易写错的还有"垦造""整治""预控"等。

## 保留的原图逻辑骨架

村庄、零星永农、连片永农、城镇村、产创预控区、河流、高速国省道、山地丘陵、园地（含缓冲带）——骨架保留、画法重做，这是"含义不变"的最小集合。改动前先把原图的图例和标注逐个抄下来，作为重绘的验收清单。

## 视觉区分策略（避免"照搬"）

原图是**亮黄+大红、高饱和色块、平面示意**。重绘统一改为**暖白纸感底 + 低饱和粉彩 + 等轴鸟瞰手绘风**（房屋、田坎、树冠带手绘线）。风格整体换掉比逐元素改颜色更能拉开距离，同时语义映射不受影响。

## 生图后的中文自查（必做，不能省）

`gpt-image-2.5-sunburst` 生成的中文小字反复出现：**叠字、乱码/缺笔、自造数字、标签丢失、题注与标签压字**，以及**文化错位**（把中国农村房屋画成欧式小楼）。

做法：用运行时里的 Python + Pillow 按区域裁剪再放大看图，逐次核对图例、核心连片区、田坎标注三处：

- 用 `PIL.Image.open(...).crop((x, y, x + w, y + h))` 输出 `crop_legend.png` / `crop_core.png` / `v6_tk.png` 等小图，再逐张看图确认字形与压字。
- 裁剪坐标要**按每一版重算**（构图会变），先用整图大致定位图例和核心块的左上角，再裁。参考：某版图例 `(1260, 290)`、核心块 `(1020, 680)`；另一版 `(1120, 800)`、图例 `(1220, 290)`，田坎区 `(600, 300)`。
- 发现一处问题就只改那一处重出一版，别在同一版里改太多（改多了会把上一版已经修好的地方弄坏）。

## 失败与重试

- 出现 `openai image request failed (524) ... bad_response_status_code` 时，直接原参数重发即可，不要改 provider/model/渠道。
- 出现 `aborted (user)`（用户中途停止）时，等用户给新要求再出图，不要自行续跑。
- 单张生成约 60–120 秒；一次编辑请求曾跑 123 秒后被中止。

## 交付口径

- 最终只 present 一张定稿，并在回复里按用户提出的每一点逐条说明"改成了什么、在图上的哪里"。
- 交付时说明尺寸与可直接插入 PPT；可主动提两个后续选项：16:9 版（与原页比例一致、便于满版铺放）、去手绘符号的纯色块"更理性版"（正式汇报用）。
- 成品与中间版本都在 `dsh-image-gen/` 下，中间版本（`image-c98e7d13.png`、`image-2a971e5d.png`、`image-6ed7da15.png` 等）不必交付，只作对比。
