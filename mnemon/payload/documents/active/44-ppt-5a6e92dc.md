# 《视频解说词》44 页 PPT 视觉识读转写：成果索引与可复用工作流

## 结论

用户要求把 PPT 转 Markdown 且**明确不要文字抽取、要视觉识别**。已交付 `视频解说词.md`（95,181 字符 / 479 行），覆盖全部 44 页。做法是把整本 PPT 渲染成 1921×1081 PNG，逐页读图后按统一三段式写作，而不是解析 XML 文本框。

## 源文件与环境事实

- 源文件：`C:\Users\zhouy\Desktop\视频解说词.pptx`，57,848,549 字节，44 页，16:9（12192000×6858000 EMU），最后修改 2026-10-19 13:58。
- 本机 **没有** 可用的 `soffice` / Office；只有 WPS（`wpp.exe`，12.1.0.28505 与 12.1.0.28802 两个版本）。渲染走 Office skill 提供的 **LibreOffice Kit CLI**（node + cli 绝对路径），不要改用系统 soffice、npx 或自建渲染管线。
- `python-pptx 1.0.2` 可用，仅用来取页数与版式尺寸；系统 `python` 指向 WindowsApps 占位符时，用 DSH 运行时里的解释器。

## 可复用工作流（PPTX → 视觉识读 Markdown）

1. **取元数据**：python-pptx 读页数与页面尺寸，确认需要渲染的页数。
2. **整本渲染**：在任务工作区内建唯一临时父目录（`.dsh-office-<guid>`），对 `render` 子目录一次批量渲染全部页；从返回的 manifest 取图片路径。
3. **分批读图**：每次读 4 张左右，边看边写，避免一次性塞入过多图片。
4. **分片写作**：先写 `part1/part2/part3.md` 分片，再合并为单个 Markdown，最后核对行数与字符数。
5. **清理**：删除临时渲染目录与分片文件，工作区只留最终 Markdown。

## 每页统一三段式（本次采用并建议沿用）

- **画面**：版式、配色、图形关系（流程箭头、表格行列、图例、区位图、改造前后对比图）、照片内容与图上压字。
- **文字**：标题、要点、表格条目、数字，按画面原样记录（含只在图里出现的数字）。
- **讲解**：这一页在整场汇报里承担什么作用、逻辑怎么走。
